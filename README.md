# Student Attendance Management System

A student attendance system using Flask and face recognition technology.

## Project Description
This project is a web-based student attendance management system developed using Flask and Face Recognition technology. The system allows administrators to manage students and automatically record attendance.

---

## Requirements

Please install the following software before running the project:

- Python 3.10 or newer
- Visual Studio Code or PyCharm
- Git (optional)

---

## Installation and Run

### Step 1: Download the project
Download and extract the project folder:

```plaintext
PhungMinhTuong_Tl1
```

---

### Step 2: Move the project folder
Move the folder to any location, for example:

```plaintext
D:\PhungMinhTuong_Tl1
```

or

```plaintext
C:\PhungMinhTuong_Tl1
```

---

### Step 3: Open the project

Open Visual Studio Code or PyCharm and navigate to the project directory.

Example:

```bash
cd PhungMinhTuong_Tl1
```

Run the following commands:

#### Create virtual environment
```bash
python -m venv venv
```

#### Activate virtual environment
Windows:
```bash
venv\Scripts\activate
```

#### Install dependencies
```bash
pip install -r requirements.txt
```

#### Run project
```bash
py run.py
```

---

### Step 4: Open the application

After running:

```bash
py run.py
```

The terminal will display:

```plaintext
http://127.0.0.1:5000/
```

Open the URL in your browser.
