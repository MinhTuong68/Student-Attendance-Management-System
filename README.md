# Student-Attendance-Management-System
A student attendance system using Flask and face recognition technology.
Hướng dẫn chạy dự án,
-	Yêu cầu cài phần mền visual, pycharm, python,vv..

Bước 1: Tải thư mục về máy và giải nén thư mục dự án có tên: PhungMinhTuong_Tl1
Bước 2: Copy thư mục có tên: PhungMinhTuong_Tl1, đưa ra ổ D hoặc C, bất kỳ chổ nào.
Bước 3: Mở visual hoặc pycharm trỏ đúng tên thư mục dự án PhungMinhTuong_Tl1 ví dụ cd PhungMinhTuong_Tl1, và chạy các lệnh như sau:
Lệnh 1 tạo môi trường ảo: 
python -m venv venv
	Lệnh 2 kích hoạt môi trường ảo
		venv\Scripts\activate
	Lệnh 3 cài đặt các thư viện
		pip install -r requirements.txt
	Lệnh 4 chạy dự án
		py run.py

Bước 4: Sau khi chạy dự án(py run.py) thì terminal sẽ cung cấp 1 đường dẫn: http://127.0.0.1:5000/
Sau đó dán đường dẫn vào trình duyệt bắt kỳ sẽ ra giao diện điểm danh sinh viên của dự án

Bước 5: Hướng dẫn sử dụng
Link truy cập vào trang điểm danh:  http://127.0.0.1:5000/
	Link truy cập vào admin quản trị: http://127.0.0.1:5000/admin/
